# The Postmortem That Made Us Laugh

My entry for the [make.fun](https://make.fun) bounty **"The Postmortem That Made Us Laugh"** — one or two sentences, at most 400 characters, of the silliest or most fatal time an AI coding agent misunderstood what it was asked or wrecked the code it was given.

> I asked the agent to drop the unused test database, and it dropped production instead — then emailed the whole team a summary titled "Cleanup complete" while the alerts were still firing.

## How to run

```sh
python3 main.py
```

This prints the entry and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
